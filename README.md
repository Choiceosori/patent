# 발명 특허 탐정단

> 아이디어를 찾아서, 권리로 설명하다 — 15. 발명과 특허, 지식재산권 교육용 웹앱

**교육용 모의출원 · 실제 특허출원이 아닙니다.** 이 웹앱은 지식재산처·특허로의 공식 출원 시스템이 아니며, 실제 접수·등록·심사·출원번호 발급·특허성 판단·수수료 납부·개인정보 수집을 하지 않습니다.

## 바로 사용하기
GitHub Pages: https://choiceosori.github.io/patent/

## 구성 (6개 탭)
| 탭 | 화면 | 핵심 기능 |
|---|---|---|
| 01 | 권리 이해관 | 지식재산권 5종 카드, 비교표, O/X 12문항, 실제 출원 절차·공식 링크 |
| 02 | 사례 탐정실 | 13개 사례 권리 분류(클릭·드래그), 해설·힌트, 특허 점검 질문 |
| 03 | 선행기술 조사실 | 아이디어 선택(내 것/예시/교사), 검색어 조합 제안, 키프리스 링크, 가상 문헌 6종, 비교 기록지 |
| 04 | 모의출원서 작성소 | 8단계 빈칸 입력 서식(웹 입력 화면 형태) + A4 실시간 미리보기, 구성요소 반복 입력, 도면 그리기/첨부 |
| 05 | 모의접수 창구 | 필수 항목 확인·해당 빈칸 이동, 교육용 모의접수(MOCK-ID) |
| 06 | 탐정 기록 보관함 | A4 인쇄(간단/상세)·PDF 안내, 조사표·전체 기록 인쇄, JSON 저장/불러오기, 기록 삭제 |

- 학습 수준: 초4 / 초5~6 / 중1~3 / 모든 설명 보기(교사) — 바꿔도 입력값 유지
- 저장: 텍스트는 `localStorage`, 도면은 `IndexedDB` (서버 전송 없음)
- 빌드 과정 없는 정적 웹앱(HTML/CSS/JS). `index.html`을 열거나 정적 호스팅에 올리면 바로 동작합니다.
